# Roadmap de 8 semanas

Objetivo: consolidar competencias prácticas de Java/Spring Boot junior en ocho semanas dejando evidencia en código, commits y PRs.

1. **REST fundamentals** — HTTP, request params/body, PUT, DELETE, ResponseEntity.
2. **Layered architecture** — Controller, Service, Repository, DI, DTOs y mapping.
3. **JPA and databases** — entidades, repositories, queries, relaciones, H2 y PostgreSQL.
4. **Validation and errors** — Bean Validation y manejo global.
5. **Security basics + JWT** — autenticación, autorización, JWT, perfiles y configuración.
6. **Testing** — JUnit 5, Mockito, WebMvcTest, DataJpaTest e integración.
7. **Docker and delivery** — Docker, Compose, OpenAPI, logging y CI.
8. **Final project** — API REST de gestión de pedidos.

## Regla
Si no puedes explicar una anotación, dependencia o clase que has añadido, todavía no cuenta como aprendizaje consolidado.
