# Semana 1 — REST fundamentals

## Objetivo
Pasar de endpoints básicos a un uso consciente de HTTP y Spring MVC.

## Spring Initializr
Para cada ejercicio: Maven, Java 21, Spring Boot 4.1.1, Group `com.luisrendonsanz`, dependencia **Spring Web**. Genera y descomprime tú el proyecto dentro de la carpeta del ejercicio.

## Documentación
- https://docs.spring.io/spring-framework/reference/web/webmvc/mvc-controller/ann-methods.html
- https://www.rfc-editor.org/rfc/rfc9110

## Ejercicios
1. Product Catalog Queries
2. Create Products
3. Update Products
4. Delete Products
5. REST Status Codes Challenge
6. Mini Library REST API

## Definition of Done
- [ ] Distingo path variables, query params y request body.
- [ ] Uso POST, PUT y DELETE con intención.
- [ ] Puedo explicar 201, 204, 400, 404 y 409.
- [ ] Cada ejercicio tiene rama y PR propios.

## Reto extra
Añade paginación manual simple al ejercicio 06, sin Spring Data.
