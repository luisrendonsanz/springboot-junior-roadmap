# Semana 7 — Docker and delivery

## Objetivo
Pasar de “funciona en mi IDE” a una API reproducible, documentada y verificable.

## Spring Initializr
Reutiliza o genera proyectos con Maven, Java 21 y Spring Boot 3.x estable. Las herramientas principales de esta semana se añaden alrededor de la aplicación: Docker, Compose, OpenAPI y CI.

## Documentación
- https://docs.docker.com/
- https://docs.spring.io/spring-boot/reference/packaging/container-images/
- https://spec.openapis.org/oas/latest.html
- https://docs.github.com/actions

## Definition of Done
- [ ] Puedo construir y ejecutar una imagen Docker.
- [ ] App y PostgreSQL se levantan de forma reproducible.
- [ ] La API tiene documentación navegable.
- [ ] Los logs ayudan sin filtrar secretos.
- [ ] CI ejecuta las pruebas existentes.
- [ ] Un tercero puede seguir mi README.

## Reto extra
Reduce el tamaño de la imagen o mejora el tiempo de build y explica el trade-off. No introduzcas Kubernetes.
