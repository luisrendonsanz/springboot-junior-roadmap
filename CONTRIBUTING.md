# Contributing / Learning Workflow

Cada ejercicio debe dejar evidencia clara de progreso.

## Flujo
1. Actualiza `main`.
2. Crea `feat/week-XX-ex-YY`.
3. Genera el proyecto con Spring Initializr dentro de la carpeta del ejercicio.
4. Implementa en commits pequeños.
5. Verifica los criterios de aceptación.
6. Abre PR hacia `main`.
7. Revisa tu diff antes del merge.

## Conventional Commits
Ejemplos: `feat: implement product creation endpoint`, `test: add invalid product cases`, `refactor: extract product mapping`, `docs: add exercise notes`, `chore: configure postgres profile`.

Evita mensajes vagos como `changes`, `final` o `fix stuff`.

## Pull Requests
Explica objetivo, decisiones, verificación y aprendizaje. No mezcles varios ejercicios en un mismo PR.
